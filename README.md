## Проект 1. Анализ рынка жилой недвижимости — Самара

[Открыть ноутбук](Project_1_Real_Estate_Market_Analysis_Samara.ipynb)

**Вопрос из практики:** от чего зависит цена квартиры и насколько заявленная цена соответствует рыночной — это приходится оценивать при экспертизе сделок.

**Что сделано:**
- очистка данных и разведочный анализ (EDA) по 500 сделкам вторичного рынка;
- разбор факторов цены: площадь, район (9 районов Самары), ремонт, год постройки, этаж;
- линейная регрессия для оценки стоимости квартиры.

**Что показал анализ:**
- площадь — сильнейший числовой предиктор цены (корреляция около 0,79);
- цена за м² между историческим центром и окраинами различается более чем вдвое;
- евроремонт добавляет к стоимости примерно 27%;
- модель объясняет около 94% разброса цен (R² ≈ 0,94), средняя относительная ошибка ~9%. Для предварительной прикидки годится, отчёт оценщика не заменяет.

## Проект 2. Анализ претензионной и судебной работы

[Открыть ноутбук](Project_2_Analysis_of_legal_claim_handling_activities.ipynb)

**Вопрос из практики:** какие споры выигрываются чаще, где претензия эффективнее суда, как срок рассмотрения влияет на исход — от этого зависит стратегия ведения дел.

**Что сделано:**
- анализ 400 споров по недвижимости, строительству и ЖКХ;
- структура нарушений и сумм требований;
- процент побед по типам споров и стадиям, динамика по годам, связь срока и исхода.

**Что показал анализ:**
- выше всего взыскание по задолженностям: по оплате ~79% побед, по ЖКХ ~67%, при коротких сроках и небольших суммах;
- споры по ДДУ (ФЗ-214) — самые крупные суммы, но выигрываются реже среднего (~55%): неустойку суды часто снижают по ст. 333 ГК РФ, поэтому «крупное на бумаге» требование редко удовлетворяется полностью;
- по стадиям сильнее всего суд первой инстанции (~73%), слабее всего апелляция (~57%);
- выигранные дела в среднем идут дольше (медиана ~113 дней против ~88): победы чаще берут в суде, а быстрые претензии и мировые закрываются раньше.
